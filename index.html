WRF-Chem-Polar

A regional chemistry-climate model based on WRF-Chem, with enhancements for the polar regions, developed at IGE and LATMOS in France.

Our main Git repositories

  • The model code of WRF-Chem-Polar
  • Our wrfpp Python package to post-process WRF and WRF-Chem outputs
  • Our infrastructure code, which we use for:
    • Compiling WPS and WRF-Chem
    • Preprocessing data
    • Running the model
